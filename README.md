# Sergei Markelov Portfolio

Static GitHub Pages version of the Sergei Markelov personal site.

The homepage is a self-contained arcade-style snake game with a glitch intro and win-state contact menu.

## Publish on GitHub Pages

1. Create or open the `markelov` repository.
2. Upload `index.html`, `CNAME`, `.nojekyll`, and this `README.md` to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Set the source to the default branch and root folder.
5. Point `sergeimarkelov.com` DNS to GitHub Pages, then keep the `CNAME` file in the repo.

## Notes

The page uses one remote image for the spaceship and loads the Press Start 2P font from Google Fonts.
